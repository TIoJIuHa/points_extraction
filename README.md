# Сравнение подходов к извлечению ключевых точек на изображениях

В ноутбуке [comparison.ipynb](comparison.ipynb) представлено сравнение как традиционных, так и нейросетевых подходов к экстракции маркеров на изображениях.

В ноутбуке [retrained_superpoint_validation.ipynb](retrained_superpoint_validation.ipynb) представлена оценка по метрике отслеживаемости ключевых точек модели SuperPoint, дообученной на кадрах полета беспилотника по лесистой местности.

Скрипт с кодом для формирования датасета: [export_detections.py](export_detections.py)

Репозиторий с кодом для дообучения SuperPoint: [pytorch-superpoint](https://github.com/TIoJIuHa/pytorch-superpoint)
